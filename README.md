# SDL Or Simple DirectMedia Layer

It's cross-platform development library written in C that provides low-level access to audio, keyboard, mouse, joystick, and graphics hardware.

# Main subsystems

Subsystem	Purpose

Video:  	Window creation, rendering, 2D graphics
Audio:  	Sound playback and recording
Events: 	Keyboard, mouse, joystick input
Joystick/Gamepad	Controller support
Timer:  	High-resolution timing
Threads:	Cross-platform multithreading
Filesystem:	File I/O abstraction

# Setting up SDL 2 on Linux

**Debian and Ubuntu**

apt-cache search libsdl2

apt-get install libsdl2-dev


**Fedora and CentOS**

yum search SDL2-devel

yum install SDL2-devel
